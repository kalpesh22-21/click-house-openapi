token-service "{{ .Release.Name }}" deployed to namespace "{{ .Release.Namespace }}".

In-cluster base URL:
  http://{{ include "token-service.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local

Point the ClickHouse API at this issuer (its config / Secret):
  OIDC_JWKS_URL = http://{{ include "token-service.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local/.well-known/jwks.json
  OIDC_ISSUER   = {{ .Values.config.TOKEN_ISSUER }}
  OIDC_AUDIENCE = {{ .Values.config.TOKEN_AUDIENCE }}

Mint a token for a user (from inside the cluster):
  curl -s -X POST \
    -H "Authorization: Bearer $TOKEN_ISSUER_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"user_name":"alice"}' \
    http://{{ include "token-service.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local/token
